# Meet Abomination81 Toolkit.

**v0.13.2** · Built by [abomination81](https://abomination81.com) · [X @abomination81](https://x.com/Abomination81)

Video Downloader is now **Abomination81 Toolkit**. The new name appears in Chrome's extension list, toolbar, right-click menu group, settings, screenshot preview and installer.

One extension for ad protection, compatible MP4 and MP3 downloads, original photos, metadata cleanup, full-page screenshots, optional-cookie rejection, popup controls, video controls, copying, clean links and local image text recognition. The black-and-green design stays.

Also fixes an update timing issue where an old video-control scan could run after Chrome replaced the extension. Old controls now retire cleanly while the replacement reconnects to your open page.

**Already using the unified extension?** The signed update installs automatically. Your settings, download history and installed folder stay in place. No new permissions or reinstall.

The installer archive is still named `Video-Downloader.zip` so existing automatic updaters and download links keep working. Older companion installations need the [one-time unified setup](https://abomination81.com/video-downloader/).
