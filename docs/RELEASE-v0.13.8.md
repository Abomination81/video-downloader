# Abomination81 Toolkit v0.13.8

Reddit downloads work again for videos whose audio sample tables include unused padding. The verifier now counts playable packets before rejecting a mismatch, while still rejecting missing content and enforcing metadata removal.

The selected Reddit player’s master playlist now takes priority over its current preview rendition, keeping highest-quality compatible MP4 as the default. Failed jobs also retain a visible toolbar badge and an explanation in the Toolkit menu.

Existing unified installations receive this signed update automatically. To get it now, use **Toolkit → Settings → Check for updates**, then close Toolkit tabs to activate it.
