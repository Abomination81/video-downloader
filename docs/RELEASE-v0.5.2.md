# Video Downloader v0.5.2

Automatic signed updates, with an extra guard for downloads that are still being selected or handed to the helper. An update waits for these foreground actions as well as active jobs and open extension UI.

Includes the Mac background updater, independent native-runtime preparation, verified packages, separate helper runtimes, interrupted-update recovery and automatic reconnection of existing pages. No Terminal or repeated installer is needed for future signed helper/extension updates. Settings and finished downloads are kept.

**From 0.4.x or the initial 0.5.0 build:** run this installer once, reload Video Downloader at `chrome://extensions`, and refresh open pages. Keep Developer mode enabled. **0.5.1 installations update automatically.**

Mac checks run on demand or every six hours. Other platforms check while Chrome runs. Shared system tools and new Chrome permission requirements keep their normal setup/approval paths. Windows installation remains unverified on Windows.
