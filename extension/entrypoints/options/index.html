Start a download

  1. Play the video so its stream can be detected.
  2. Right-click it and choose Download video.
  3. If the menu is blocked, use the extension button or Alt+Shift+V.

If several videos match, choose one from the list. DRM, live recording, WebRTC, and some custom players are not supported.

One extension, every tool

Video, MP3, photos, screenshots, ad protection and browsing tools are built in. Chrome groups matching right-click commands under Abomination81 Toolkit. No companion extensions are needed.

Upgrading from the old bundle? Remove or disable its Audio, Ad Protection, YouTube Protection and Full Page Screenshot companions in Chrome to avoid duplicate tools.

Installation and updates

Installed extension folder: Run the installer and check the helper connection.

  1. Run Install.command on Mac or Install-Windows.cmd on Windows from the download bundle.
  2. Open chrome://extensions and enable Developer mode.
  3. Click Load unpacked and select the extension folder opened by the installer.

Automatic updates are enabled after this installation. Copies older than 0.5.1 need this installer once and one extension reload to enable them. Future signed updates install without Terminal or reinstalling. Finished files and settings are kept.

What metadata removal means

The helper removes descriptive tags, GPS, source timestamps, chapters, cover art, extra data tracks, and unregistered H.264/HEVC user data. It keeps technical information needed for playback, including HDR and orientation. It checks the file before publishing it. Visible watermarks remain part of the picture.
