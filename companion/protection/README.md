# Ad Protection by Abomination81

A renamed distribution of **uBlock Origin Lite**, by Raymond Hill, pinned to release 2026.1103.1743. Modified by Abomination81 on 2026-11-04. This distribution and its integration files are GPL-3.0-or-later. Upstream attribution and licenses remain included. The downloader, helper and other independently running components keep their own licenses.

Default filtering is Complete, including upstream network rules, scriptlets, resource replacements, extended cosmetic rules and popup filtering. Loopback sites, Zillow and LoopNet (including subdomains) are excluded. The two compatibility exceptions remain active through saved mode changes. The upstream dashboard retains per-site modes, regional lists, custom filters and troubleshooting. Optional user-script features may require Chrome's Allow user scripts control; bundled default protections work without enabling that switch. No universal ad-removal claim is made.

`upstream/chromium` is the unmodified upstream release tree; `upstream/uBlock` contains the corresponding upstream source at the recorded commit. `provenance.json` verifies every included file. Our builder changes only branding/identity, the initial filtering mode and built-in compatibility exceptions, and adds a narrow parent status/control/update interface. It exports the engine's initialization promise and keeps its calendar-version migration checks separate from the downloader's bundle version; the filtering algorithms remain upstream code. Country-flag PNGs are packed into a local data-URL module to keep the installer within older helpers’ file-count limit; all flags and their original source/attribution are retained. All parent requests require the downloader's actual background sender, bounded hostnames, exact keys and recognized commands. No caller-supplied script, URL or filter code is accepted through that interface.

First unzip the included `protection-companion-source.zip`. From its `protection-companion-source` directory or from the repository, run `node scripts/build-protection-companion.mjs` with Node 22+ to reproduce the packaged companion offline. No npm dependencies are needed for this packaging step. The full upstream build instructions and licenses are included under `upstream/`. Filter/engine refreshes arrive in signed downloader releases; do not edit pinned files without updating and reviewing provenance.

Load `protection-companion` once in Chrome. Its toolbar provides the full engine's controls. The downloader's main menu can pause/resume general protection and pause a site. Reload already-open pages after changing engines. Disable any separately installed third-party ad blockers to avoid conflicting filtering.

Bundle 0.12.0 adds a background-only `protection-annoyances` boolean command for the fixed `annoyances-overlays`, `annoyances-notifications` and `annoyances-widgets` lists. Disabling it removes only lists this integration added, preserving preexisting and imported lists. Cookie-hiding lists are not enabled: the main component performs actual consent rejection. No arbitrary list URL or rule is accepted through this bridge.
