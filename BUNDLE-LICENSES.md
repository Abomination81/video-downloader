# Bundle licenses

Cookie rejection uses unmodified **DuckDuckGo Autoconsent 18.0.0** under MPL-2.0 (https://github.com/duckduckgo/autoconsent). Its rules and implementation source, including its license, are supplied in `browsing-source.zip`. Our integration configures opt-out only, disables cosmetic-only rules, and executes only bundled snippet functions; it does not download scripts or send reports.

Local image text recognition uses **Tesseract.js 7.0.0**, **Tesseract.js-core** and the **Tesseract English language data**, under Apache-2.0 (https://github.com/naptha/tesseract.js, https://github.com/naptha/tesseract.js-core, https://github.com/tesseract-ocr/tessdata_best). Their distributed package files, notices and pinned versions are supplied in `browsing-source.zip`. The root MIT license does not replace these dependency licenses. OCR uses packaged worker, WebAssembly and language data; image pixels and recognized text are not sent to an OCR service.

The **combined Chrome extension** is distributed under **GPL-3.0-or-later** (`LICENSE-GPL-3.0`) and includes modified **uBlock Origin Lite 2026.1103.1743**, by Raymond Hill and contributors. The original first-party downloader/helper and Still 1.1.0 screenshot code retain their MIT notices in `LICENSE`; those notices do not replace the GPL terms of the combined extension. Upstream library, font and filter-data licenses remain in their source trees.

Every installer contains `extension-source.zip`: complete corresponding first-party source, pinned engine source and release files, provenance hashes, integration patches, package lock, build scripts and tests. Run `npm ci && npm run build` from that source to reproduce the extension. The engine and screenshot inputs are hash-verified before integration. Runtime modifications are generated by `scripts/build-unified.mjs`; vendored inputs remain unchanged. The release contains one extension manifest and one worker. Legacy companion code remains in source for historical compatibility tests, but is not installed.

No standalone YouTube or basic EasyList engine is shipped in the unified runtime. uBOL's filter data and dependencies retain the notices supplied with its pinned source.
